Bitunix 掃描器 → GitHub Actions 上雲步驟
========================================

【已完成可略過】
- repo: https://github.com/yens01/bitunix-scanner
- Secrets: TELEGRAM_BOT_TOKEN / TELEGRAM_CHAT_ID
- 工作流: .github/workflows/scan.yml（每 15 分鐘 schedule + 可手動）


【為什麼一直要手動？時間又變 +0？】
1) GitHub schedule 忙碌時會延遲或丟掉（尤其以前 */5）
2) 按「Re-run / 重新執行」只會重跑「當時那版程式」
   → 你的 #1 鎖在舊 commit，時間仍是 UTC(+0)
3) 正確做法：Actions → Bitunix Scan → 「Run workflow」開「新的一輪」
   → 才會用 main 最新碼（含台灣時間 +8）

自動成功：列表出現新 run，且寫 Scheduled（不是只重跑 #1）


【若 schedule 仍不跑：cron-job.org 外掛定時】
1) GitHub → Settings → Developer settings → Personal access tokens (classic)
   勾 repo、workflow，複製 token
2) https://cron-job.org 新增：
   URL:
   https://api.github.com/repos/yens01/bitunix-scanner/actions/workflows/scan.yml/dispatches
   Method: POST
   每 15 分鐘
   Header:
     Authorization: Bearer 你的TOKEN
     Accept: application/vnd.github+json
     Content-Type: application/json
   Body: {"ref":"main"}


【注意】
- 不要上傳 telegram.local.env
- Public：程式碼看得到，Secrets 仍保密
- 本機：啟動掃描.bat 或 python bitunix_scanner.py watch
