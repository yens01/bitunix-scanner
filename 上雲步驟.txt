Bitunix 掃描器 → GitHub Actions 上雲步驟
========================================

【你要做的事】約 10～15 分鐘

1) 打開 https://github.com 登入（你的帳號 yens01）

2) 右上角 + → New repository
   - Repository name: bitunix-scanner（可自訂）
   - 建議選 Private（私人，比較安全）
   - 不要勾 Add README
   - 按 Create repository

3) 建立好後，GitHub 會顯示「推送現有資料夾」指令。
   在本機「分析」資料夾打開終端機，依序執行：

   git init
   git add .
   git commit -m "Add Bitunix scanner with GitHub Actions"
   git branch -M main
   git remote add origin https://github.com/yens01/bitunix-scanner.git
   git push -u origin main

   （若 repo 名稱不同，把網址改成你的）

4) 到該 repo → Settings → Secrets and variables → Actions
   → New repository secret，新增兩個：

   Name: TELEGRAM_BOT_TOKEN
   Value:（你 telegram.local.env 裡的 BOT TOKEN）

   Name: TELEGRAM_CHAT_ID
   Value:（你的 CHAT ID）

5) 到 repo → Actions
   - 若第一次要同意工作流，按 Enable
   - 點左邊「Bitunix Scan」→ Run workflow → Run workflow
   - 等跑完，看 Telegram 有沒有訊息（沒警報時只會在 log 顯示「推0」）

6) 之後每 5 分鐘自動掃一轮（免費額度內）。
   本機仍可繼續用：啟動掃描.bat 或 python bitunix_scanner.py watch


【注意】
- 不要上傳 telegram.local.env（已在 .gitignore）
- 免費帳號 Actions 有月用量；*/5 通常夠用，太兇可改成 */10
- 排程用 UTC；想改頻率：編輯 .github/workflows/scan.yml 的 cron
