自動排程（已優化版）
====================

【現況架構】
- cron-job.org 每 15 分鐘 → 打 GitHub API
- 只跑「Auto Scan」（workflow_dispatch）
- 「Bitunix Scan」改為純手動，避免雙排程重複推播


【cron-job.org 建議】
URL（用數字 ID）：
  https://api.github.com/repos/yens01/bitunix-scanner/actions/workflows/380372933/dispatches
Method: POST
Body: {"ref":"main"}
Headers:
  Authorization: Bearer 你的TOKEN
  Accept: application/vnd.github+json
  Content-Type: application/json

頻率建議：
- 預設 15 分鐘：訊號較即時，Actions 用量中等
- 想省用量：改 20～30 分鐘也行（冷卻已是 45 分，不會更密推同幣）


【這次優化了什麼】
1. 拿掉 GitHub 內建 schedule（你帳號不穩，且會跟 cron-job 重複）
2. 加 concurrency：上一輪沒跑完會取消，避免疊兩次掃描
3. 冷卻 cache 改穩：先還原再確保檔案存在再存回
4. 掃描池 n=30：省時間／額度，過濾已夠嚴
5. timeout 縮到 8 分鐘


【成功長怎樣】
Actions → Auto Scan 每隔約 15 分鐘多一筆 #2 #3 #4…
Telegram 有 YES／靠近區才推；沒訊號不響屬正常


【安全】
- Token 勿貼聊天
- 洩露立刻到 https://github.com/settings/tokens Revoke
